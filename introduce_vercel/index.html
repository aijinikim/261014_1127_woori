01Vercel이란?

Vercel은 웹사이트와 서버 함수를 올려 주는 클라우드 배포 플랫폼입니다. 서버를 직접 빌리고 설정할 필요 없이, 폴더를 올리면 몇 초 만에 https://내프로젝트.vercel.app 주소가 생깁니다.

Next.js를 만든 회사이지만, 지금까지 만든 HTML·CSS·JS 파일만 있는 사이트도 그대로 올릴 수 있습니다.

즉시 배포명령 한 줄 또는 GitHub push 한 번으로 배포 완료
Preview / Production배포마다 미리보기 주소가 따로 생기고, 확인 후 본 서비스로 승격
Functionsapi/ 폴더의 JS 파일이 자동으로 서버 API가 됨
환경변수API 키를 코드가 아닌 Vercel에 안전하게 보관
HTTPS · CDN보안 인증서와 전 세계 캐시가 자동 적용
Hobby 플랜 무료개인·학습용은 무료. GitHub 계정으로 가입

Streamlit · Gradio 배포와 무엇이 다른가요?

Streamlit/Gradio는 파이썬 서버가 계속 켜져 있어야 하는 앱입니다. Vercel은 정적 파일 + 요청이 올 때만 잠깐 실행되는 함수(서버리스) 구조라서 HTML/JS 웹앱에 잘 맞습니다.

03방법 1 — Claude Code로 배포하기

Claude Code는 터미널 명령을 대신 실행할 수 있습니다. 로그인만 우리가 하고, 나머지 vercel 명령은 Claude에게 맡깁니다.

① 로그인 (사람이 직접)

브라우저 인증이 필요하므로 Claude Code 입력창에서 !를 붙여 직접 실행합니다.

! npx vercel login

② Claude에게 요청

01_static_deploy 폴더를 Vercel에 미리보기로 배포하고 주소를 알려줘

Claude가 실행하는 명령은 대략 다음과 같습니다.

# 폴더로 이동 후 Preview 배포 (처음엔 프로젝트 이름 등을 묻는다 → --yes로 기본값)
cd 01_static_deploy
npx vercel --yes

# 출력 예시
Preview: https://01-static-deploy-abc123-myname.vercel.app

③ 확인 후 본 서비스로

미리보기 잘 나왔어. production으로 올려줘
npx vercel --prod --yes
Production: https://01-static-deploy.vercel.app

이런 요청도 가능

"배포 목록 보여줘"npx vercel ls
"배포가 실패했어, 원인 찾아줘"npx vercel inspect <주소> --logs로 빌드 로그 확인
"이전 버전으로 되돌려줘"npx vercel rollback

처음 배포하면 폴더 안에 .vercel/이 생깁니다. 이 폴더가 "이 폴더 = 그 Vercel 프로젝트" 연결 정보이므로 git에는 올리지 않습니다.

04방법 2 — Vercel MCP 연결하기

MCP(Model Context Protocol)는 Claude에게 외부 서비스용 "도구"를 꽂아 주는 표준입니다. Vercel 공식 MCP 서버를 연결하면 Claude가 CLI 출력을 해석하는 대신, 내 Vercel 계정의 프로젝트·배포·로그를 도구로 직접 조회합니다.

① 등록

터미널(또는 Claude Code에서 ! 붙여서):

claude mcp add --transport http vercel https://mcp.vercel.com

또는 프로젝트 폴더에 .mcp.json을 두면 팀원 모두가 같은 설정을 씁니다 (02_vercel_mcp/.mcp.json).

{
  "mcpServers": {
    "vercel": { "type": "http", "url": "https://mcp.vercel.com" }
  }
}

② 인증

Claude Code에서 /mcp 입력 → vercel 선택 → 브라우저에서 Vercel 로그인·권한 허용(OAuth). API 토큰을 직접 복사할 필요가 없습니다.

③ 사용

내 Vercel 프로젝트 목록이랑 각 프로젝트 최근 배포 상태 알려줘
03-claude-chat 최근 배포 빌드 로그 보고 왜 실패했는지 설명해줘
Vercel 문서에서 Functions 실행 시간 제한 찾아줘
구분방법 1 · CLI방법 2 · MCP
연결 방식vercel login 토큰OAuth 인증
잘하는 일배포 실행, 환경변수 추가프로젝트·배포·로그 조회, 문서 검색
필요한 것Node.jsMCP 지원 클라이언트 (Claude Code, Claude 앱)

실무에서는 둘을 같이 씁니다. 배포는 CLI, 상태 확인과 문제 해결은 MCP.

05방법 3 — Claude API 챗봇 배포하기

이번엔 Claude가 배포를 도와주는 쪽이 아니라 배포되는 앱 안에서 동작합니다. 핵심은 API 키를 브라우저에 절대 두지 않는 것입니다.

폴더 구조 — 03_claude_chat/

03_claude_chat/
├─ index.html, style.css, script.js   # 채팅 화면
├─ api/chat.js                        # 서버 함수 (Vercel이 자동 인식)
├─ package.json                       # @anthropic-ai/sdk
├─ .env.example                       # 키 이름 견본
└─ .gitignore                         # .env, node_modules, .vercel 제외

핵심 코드 — api/chat.js

import Anthropic from '@anthropic-ai/sdk';
const client = new Anthropic();   // 키는 환경변수에서 자동으로 읽음

export async function POST(request) {
  const { messages } = await request.json();
  const stream = client.beta.messages.stream({
    model: 'claude-opus-5-5',
    max_tokens: 64000,
    output_config: { effort: 'low' },
    betas: ['server-side-fallback-2026-07-01'],
    fallbacks: 'default',
    system: '당신은 친절한 한국어 도우미입니다.',
    messages,
  });
  // text_delta 조각만 골라 ReadableStream 으로 브라우저에 흘려보냄
  ...
}

export async function POST처럼 HTTP 메서드 이름으로 함수를 내보내면, 프레임워크 없이도 Vercel이 /api/chat 주소로 연결합니다.

배포 순서

cd 03_claude_chat
npm install

# 1) 프로젝트 연결 + 첫 Preview 배포
npx vercel --yes

# 2) API 키를 Vercel 환경변수로 등록 (값은 프롬프트에 붙여넣기)
npx vercel env add ANTHROPIC_API_KEY production
npx vercel env add ANTHROPIC_API_KEY preview

# 3) 환경변수 반영을 위해 다시 배포
npx vercel --prod --yes

로컬 테스트: .env.example을 .env로 복사해 키를 넣고 npx vercel dev → http://localhost:3000.

Claude Code에게 통째로 맡기기

03_claude_chat을 Vercel에 배포해줘. ANTHROPIC_API_KEY 환경변수 등록이 필요하면 나한테 키 입력하라고 알려줘
보안 주의
· API 키를 script.js나 HTML에 넣으면 누구나 개발자 도구로 볼 수 있습니다. 반드시 서버 함수 + 환경변수.
· .env 파일은 절대 git에 올리지 마세요 (.gitignore에 포함됨).
· 배포 주소는 공개됩니다. 주소를 아는 누구나 내 키로 Claude를 호출할 수 있으니, 수업이 끝나면 배포를 내리거나 키를 폐기하세요. Anthropic 콘솔에서 월 사용 한도를 걸어 두면 안전합니다.
